# 🤖 AI SMM Agent: Content Automation Bot

An intelligent Telegram ecosystem designed to automate the heavy lifting of social media management. This tool leverages **Google Gemini Pro** to transform niche-specific contexts into high-engaging posts, Reels scripts, and strategic hashtag sets.

## 🎯 Business Value
Traditional content creation takes hours of brainstorming. This MVP demonstrates how **AI-Augmented workflows** can reduce the "zero-to-one" content phase by **~90%**, allowing creators to focus on strategy rather than syntax.

## 🛠 Tech Stack
* **Engine:** Python 3.10+
* **LLM Core:** Google Gemini Pro (Generative AI)
* **Interface:** `aiogram` (Asynchronous Telegram Framework)
* **DevOps:** `python-dotenv` for secure environment management.
* **Architected with:** Claude 3.5 (AI-assisted engineering for rapid prototyping).

## 🚀 Key Features
* **Niche Intelligence:** Tailors Tone of Voice (ToV) for industries like Tech, Lifestyle, and Finance.
* **Format Flexibility:** Generates structured scripts for Reels/Shorts and copy for static posts.
* **Smart Hashtagging:** Categorizes tags by reach and relevance.
* **Async Performance:** Built for speed and non-blocking user interactions.

## 📦 Installation
1. **Clone & Env:** Create a `.env` file with `TELEGRAM_BOT_TOKEN` and `GEMINI_API_KEY`.
2. **Install:** `pip install -r requirements.txt`
3. **Launch:** `python main.py`
